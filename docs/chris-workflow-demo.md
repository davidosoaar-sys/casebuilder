# Demonstrate Chris’s actual workflow

Use a separate test deal and clearly label the inputs as fictional. The point is
to demonstrate the path from discovery evidence to a usable business case, not
to imply that sample figures describe Nike, Spotify or another customer.

1. Create a deal. Let company branding load, then use the input sheet. Expand
   **Case context** only if the discovery material already establishes the team,
   workflow and current problem. These notes are optional and never alter the math.
2. Supply a realistic fictional discovery note through the existing linked-material
   workflow. For example: “Our platform team supports checkout services. Finding
   a service owner during an incident is difficult. We have 500 engineers.” Ask
   the project agent to propose context and input edits from that material. Review
   its proposals before applying them; the current server/worker and funded model
   must be configured for a live agent demo.
3. Use **Suggest values** for remaining empty inputs. Do not let industry estimates
   stand in for customer facts. Leave unavailable inputs empty or record Chris’s
   assumptions explicitly using the existing input controls.
4. Open **Evidence review** in the input sheet. Show the discovered input’s source
   link and exact quote, its state, and the figures that use it. Expand calculated
   figures to inspect the existing arithmetic. Copy the open questions for a
   follow-up email. No separate evidence document has to be maintained.
5. Open the deck. A new deal uses this sequence: company introduction, modeled
   Portal/self-hosting cost comparison, value drivers, what changes, stakeholder
   framing, then the overall modeled impact. A higher Portal cost is shown as
   higher, not disguised as a saving. Capacity value is not a promised budget cut.
6. Edit one input and show the corresponding figures update. Show PDF, slides,
   one-pager and website previews. The website’s scenario controls update the
   same narrative and figures. Source quotes and confidence remain private.
7. Make one direct text/design edit and export the chosen format or MD file.
   Reopen the deal to demonstrate the existing automatic saving.

Existing edited decks retain their order and copy. The updated narrative is the
default for new cases and newly inserted built-in pages; optional context can be
used in current cases without rebuilding their authored decks.
