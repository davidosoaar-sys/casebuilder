Research the people behind the stakeholder roles using the **account-research** skill.

Arguments: $ARGUMENTS

If a case file was not named, use the single `*.case.json` in the working folder (ask if there are several). If a role was named, research only that one; otherwise research every stakeholder in the case. Follow the skill's rules exactly: every person needs a source URL, never guess an email or a LinkedIn URL, professional information only. For several roles you may run one **account-researcher** agent per role in parallel. Report what you found, what is missing, and remind the user to verify before reaching out.
